# 🤖 Renovate Config

A shareable Renovate config with the following defaults:
- safe automerge for minor/patch with a 3‑day release‑age delay
- semantic commits
- clean branch naming
- full merge‑confidence badges

## 🕹️ Usage

```jsonc
// renovate.json
"extends": ["github>kh4f/renovate-config"],
```
